# Design Brief

## Objetivo

Describir el propósito principal del sitio o interfaz y el resultado de negocio que se espera.

## Público

Perfiles de usuario, necesidades principales, contexto de uso y nivel de familiaridad técnica.

## Estilo visual

Personalidad de marca, sensación a transmitir, palabras descriptivas y dirección estética acordada.

## Paleta

Colores principales, colores de acento, colores prohibidos, uso esperado de fondos y textos.

## Tipografía

Familias elegidas para títulos, cuerpo y UI; pesos; tamaños aproximados; estilo general.

## Componentes principales

Lista de bloques o componentes que debe incluir la interfaz: navegación, hero,CTA, testimonios, formularios, footer, etc.

## Layout

Estructura de página, jerarquía de contenidos, disposición de secciones y comportamiento en desktop.

## Responsive

Cómo debe adaptarse el diseño en tablet y móvil; qué contenido tiene prioridad.

## Animaciones

Nivel de animación deseado, tipo de transiciones permitidas, elementos que deben permanecer estáticos.

## Accesibilidad

Requisitos de contraste, navegación por teclado, lectores de pantalla, tamaños mínimos de interactivos.

## Restricciones

Limitaciones técnicas, tecnologías obligatorias, tiempos, presupuesto o dependencias externas.

## Requisitos funcionales

Qué debe hacer el sitio: flujos, formularios, integraciones, estados de error, validaciones.

## Requisitos no funcionales

Rendimiento, SEO, escalabilidad, mantenibilidad, compatibilidad con navegadores.

## Referencias

Sitios analizados, estilos de referencia y decisiones sobre qué conservar o descartar.

## Decisiones tomadas durante la entrevista

Puntos clave acordados con el usuario, cambios respecto a conceptos iniciales y razones de cada decisión.
